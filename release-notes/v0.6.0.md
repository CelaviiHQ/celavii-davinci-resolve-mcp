# v0.6.0 — v5 Port: Agent Coverage Catch-up

**Released:** 2026-05-26
**Resolve target:** 21.0.0b.20 (verified live; older builds version-gated)

This release closes the agent-tooling gaps identified during the
`samuelgursky/davinci-resolve-mcp` audit. 42 new MCP tools, 9 bundled
templates, and a Phase 0 helper layer that prevents
`'NoneType' object is not callable` errors on builds missing newer Resolve
methods.

## Highlights

- **Resolve-native AI**: Magic Mask, Smart Reframe, Stabilize, native
  Subtitles-from-Audio (17 languages, 3 presets), Scene-cut detection,
  per-clip and per-folder Native Transcription.
- **Authoring surfaces**: Fuse plugin scaffolding (4 templates +
  install/validate/render) and DCTL scaffolding (5 templates + install/
  validate/render + node-apply bridge). Both confined to user-level
  directories with traversal-safe path resolution and source validators.
- **Fusion safety**: 4 read-only comp-introspection tools so VFX agents
  can probe before mutating — boundary report, paginated graph snapshot,
  animated-input finder, render-safety check.
- **Project setters**: 7 typed wrappers around `project.SetSetting()` —
  color science, color space, timeline format, proxies, optimized media,
  cache mode, Superscale.
- **Fairlight presets** (Resolve 20.2.2+): list + apply, version-gated.
- **Per-clip grade reset**: snapshot-first, hook-matched destructive op.
- **Multicam (partial)**: `cutmaster_auto_sync_audio` ships;
  `setup_multicam_timeline` deferred until Blackmagic publishes a
  documented multicam-create method.

## Deferred (documented, not abandoned)

1. **C1 keyframes** — `AddKeyframe`/`DeleteKeyframe`/`GetKeyframes` are not
   in the documented Resolve scripting API and return `None` on live
   probe. Investigation logged in `api_verification.md` § Rejected.
2. **`cutmaster_setup_multicam_timeline`** —
   `MediaPool.CreateMultiCamClipWithMediaItems` not callable on
   21.0.0b.20. Same rationale.

Both revisit when Blackmagic publishes a documented surface.

## Verification discipline

Every wrapper is mapped to a verified API row in
[`Implementation/cutmaster_ai/v5/api_verification.md`](../Implementation/cutmaster_ai/v5/api_verification.md).
Five first-draft API claims (e.g. `ModifyKeyframe`,
`SetKeyframeInterpolation`, `ApplyFairlightAudioMixPreset`,
`GetFairlightAudioMixPresets`) were caught and removed during validation
before code was written. `hasattr()` is unreliable on Resolve's
`PyRemoteObject`; the canonical check is
`callable(getattr(obj, name, None))`.

## Upgrade

```bash
pip install --upgrade cutmaster-ai
# then restart Claude Code / Claude Desktop / Cursor
```

No breaking changes; all v0.3.0 tools behave identically. New tools
appear with the standard `cutmaster_` prefix.
